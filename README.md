# The Sopranos Restaurant & Lounge Website

Welcome to the repository for **The Sopranos Restaurant & Lounge** web platform[cite: 1, 4]. This project is a multi-page website designed to showcase the venue's fine dining, craft cocktails, VIP nightlife events, operating details, menu items, and reservation facilities[cite: 1, 2, 3, 5, 6].

---

## 📌 Project Overview

**The Sopranos Restaurant & Lounge** is a premier fine dining and entertainment destination located in Northern Roodepoort, Gauteng, South Africa. The website offers a responsive user interface allowing guests to explore food and drink options, check venue opening hours, get in touch, and book table reservations[cite: 2, 3, 6].

### Key Pages
* **Home (`index.html`):** Hero section featuring current promotions, featured specials, and quick site links[cite: 4].
* **About Us (`about.html`):** Overview of the establishment history, culinary philosophy, vision, and site links[cite: 1].
* **Menu (`menu.html`):** Detailed breakdown of burgers, wings, meat platters, signature cocktails, and event specials/deals[cite: 6].
* **Services (`services.html`):** Highlights of gourmet dining, signature cocktail bar, and VIP lounge event hosting[cite: 5].
* **Reservations (`enquiry.html`):** Interactive booking request form for tables, parties, and VIP groups[cite: 3].
* **Contact Us (`contact.html`):** Business operating hours, physical address, contact details, and a messaging form.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure across all pages[cite: 1, 2, 3, 4, 5, 6].
* **CSS3:** Custom styling linked via `css/style.css`[cite: 1, 2, 3, 4, 5, 6].
